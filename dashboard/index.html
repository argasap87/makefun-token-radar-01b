How the value is worked out

Implied value = TVL × peer multiple × growth × age. The peer multiple is the median market-cap / TVL of the tokened protocols in the same category (at least 3 peers, otherwise the market-wide median …), clamped to 0.02–2.00. Growth reads the 7-day TVL change; age reads how long the protocol has run with no token recorded. Nothing here is a hardcoded list of names — every number comes from the snapshot itself, so the same program ranks a snapshot taken next month.

“Records no token” is what the snapshot says — it is not proof a protocol has none. Implied values are this radar’s own claim, never a price and never a promise.
